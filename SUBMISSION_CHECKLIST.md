# Submission Checklist

Based on the supplied Cybersecurity Student Project Submission Guidelines.

- [x] Working implementation — Dockerized web application
- [x] Source code organized by frontend/backend/data/tests
- [x] Dataset / sample data
- [ ] Screenshots of actual execution — capture after running the Docker app
- [x] README with install/run/test instructions
- [x] Test cases and evaluation script
- [ ] Final PDF report — use `docs/PROJECT_REPORT.md` as the source/template
- [ ] Final PPT/PPTX — use `docs/PPT_OUTLINE.md`
- [ ] Live demo

## Before submission

1. Run `docker compose up --build` on Docker Desktop.
2. Open `http://localhost:8080`.
3. Capture screenshots of both modules and their results.
4. Run `python evaluate.py` and capture the metrics/confusion matrix.
5. Replace student/institute details in the report and PPT.
6. Only include data from authorized test environments.
